# 0002. Django を 5.2 LTS に留める

## ステータス

承認（2026-11-09）

## コンテキスト

本プロジェクトは Python 3.10 以上での動作をサポート要件とする。

Django の各バージョンと対応する Python は次のとおり（2026-11 時点。出典: [Django の FAQ](https://docs.djangoproject.com/en/dev/faq/install/#what-python-version-can-i-use-with-django)、[ダウンロードページ](https://www.djangoproject.com/download/)）。

| Django | Python | 備考 |
|---|---|---|
| 5.2 | 3.10〜3.14（3.14 は 5.2.8 から） | LTS。通常サポートは 2025 年 12 月に終了し、延長サポート（セキュリティ修正のみ）は 2028 年 4 月まで |
| 6.0 | 3.12〜3.14 | 延長サポートは 2027 年 4 月まで |
| 6.1 | 3.12〜3.15（3.15 は 6.1.3 から） | 最新（6.1.3）。延長サポートは 2027 年 12 月まで |
| 6.2 | 3.12〜3.15 | 次の LTS。2027 年 4 月に公開予定 |

Django 6 系は Python 3.12 以上にしか対応していない。次の LTS の 6.2 も同じである。

検討した案は次のとおり。

- Django 4.2 LTS: 延長サポートが 2026 年 4 月に終了しており、セキュリティ修正を受けられない。
- Python の要件を 3.12 以上に上げ、Django 6 系を使う: Python 3.10 以上というサポート要件を満たせない。
- Django 5.2 LTS: Python 3.10 から 3.14 までのすべてに対応し、2028 年 4 月までセキュリティ修正を受けられる。

## 決定

Django は 5.2 LTS に留め、依存は `django>=5.2.8,<6.0` と範囲で指定する。下限を 5.2.8 にするのは、開発に使う Python 3.14 に対応した最初の版だからである。

## 結果

- サポート要件である Python 3.10 から動作し、5.2 系のセキュリティ修正を依存の更新だけで取り込める。修正は 2028 年 4 月まで提供される。
- 5.2 は通常サポートが終了しているため、セキュリティ以外の不具合の修正は提供されない。
- Django 6 系の新機能は使えない。
- Django 6 系に上げるには、サポート要件を Python 3.12 以上に引き上げる必要がある。その場合はこの ADR を置き換える。
